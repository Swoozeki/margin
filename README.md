# margin

A voice-first writing companion for Android. Ideas arrive in the margins.

- **Page**: tap the ink drop and speak. Your words are transcribed on-device and saved.
- **Desk**: your captured ideas.
- **Think**: modes for talking with Claude (coming next).
- **Quick Settings tile** and **launcher shortcut** "Capture idea" open the app already listening.

Every push to `main` builds a debug APK and publishes it as a GitHub release.
